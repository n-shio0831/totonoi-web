ブランドブックに合わせて刷新しました

配色・書体・ロゴ・タブ構成・画面設計を、BRAND BOOK v2.0 と仕様方針まとめに準拠させています。

COLOR

6色の無彩色パレット

WARM WHITE / IVORY / MIST / STONE / TAUPE / CHARCOAL。「Less color. More atmosphere.」に従い、アクセントカラーを廃止しました（前版の緑を撤去）。

TYPE

明朝は「感情」、サンセリフは「UI」

問いかけ・見出しなど心に触れる言葉を明朝体に、操作系をサンセリフに分離。ロゴは細字・広トラッキング。

NAV

タブを5つに変更

Home / Journal / Column / Booking / My Page。Mood は独立タブをやめ、ブランドブック通りHomeのカードに。

ASSESSMENT

5領域・17問・5件法

REST / FEEL / KIND / VALUES / CONNECT。結果は固定のタイプ診断にせず、Primary / Secondary として提示。「診断ではありません」も明記。

REFLECTION

集計＋折れ線グラフ

Weekly＝Mood平均・よく選ばれた感情・Journal日数・問いへの回答・先週比。Monthly＝4週推移・テーマ傾向・領域の変化。AI要約は入れていません（MVP方針通り）。

PHOTO

写真をアイボリーの静物に

ブランドブックの「DO」に合わせ、明るい花畑から、やわらかい光と影のある静かな室内・布・小さな植物へ変更。使用箇所も絞りました。

友人Aに確認したいこと（6点）

  1. 設問数が「18問」と「17問」で食い違っています。本文の質問は①〜⑰の17問でした。どちらが正でしょうか（モックは17問で作成）。
  2. Session の価格・種類が2つの資料で異なります。ブランドブックは「カウンセリング60分¥8,800／マインドフルネス45分¥6,600／コンディショニング60分¥9,900」、事業計画は「30分¥4,000／50分¥7,000／3回券¥17,000」。モックは事業計画側を採用しています。どちらで進めますか。
  3. 「今日のコンディション」（睡眠・水分・歩数）がブランドブックのHome画面にありますが、事業計画・仕様方針には記載がありません。実装するとヘルスケア連携（HealthKit）と手入力機能が必要で工数が増えます。MVPに含めますか。
  4. 「マインドフルネスのヒント」も同様に新規要素です。Columnとは別のコンテンツとして毎日出す想定でしょうか。
